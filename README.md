Sales Dashboard with Python

This project creates a basic sales dashboard using Python, Pandas, Matplotlib, and Seaborn to visualize sales performance by product, region, and month.

Files

•
SalesDataset(1).csv: The raw sales data.

•
sales_dashboard.py: Python script for data processing and visualization.

•
sales_over_months.png: Line chart showing sales trends over months.

•
sales_by_state.png: Bar chart showing sales distribution by state.

•
sales_by_category.png: Donut chart showing sales distribution by product category.

•
sales_insights.txt: Text file containing key insights derived from the dashboard.
